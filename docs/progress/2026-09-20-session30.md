### 5. ✅ Bug Fix: OverflowError en Reminder Store
**Archivo modificado:** `python-service/tools/reminder_store.py`
- Problema: Test reminder programado para 2099 causaba `OverflowError: timeout value is too large` en `threading.Timer`
- Causa: `threading.Timer` en Windows usa `WaitForSingleObject` con max ~2^31 ms (~24 días)
- Fix: Agregado `_MAX_TIMER_SECONDS = 2_000_000` (~23 días). Reminders más lejanos se almacenan pero no se programan con timer. Se reprograman en el próximo restart.
- Log informativo cuando se salta el timer
