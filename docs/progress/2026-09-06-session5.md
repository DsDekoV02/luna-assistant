## Cambios Realizados

### 1. Bug Fix: Cache Binary Auto-Detect
**Archivo:** `python-service/memory/cache.py`
- **Problema:** `DiskCache.set()` requería `binary=True` explícitamente para guardar bytes
- **Solución:** Auto-detección de tipo `bytes` cuando `binary=None`
- **Impacto:** TTS audio ahora se cachea correctamente (antes se intentaba serializar como JSON)

### 2. Text Processor Mejorado
**Archivo:** `python-service/voice/text_processor.py`
- Agregada contracción `del → de el` para mejor pronunciación TTS
- Nueva función `add_pauses()`: convierte `;` y `:` en pausas más claras para TTS
- Pipeline actualizado: Step 6.5 "Add natural pauses" antes de split_sentences

### 3. Three.js Avatar
**Archivo:** `electron-app/src/avatar.js` (NUEVO)
- Clase `LunaAvatar` con:
  - Luna creciente 3D (esfera + sombra)
  - Ojos que parpadean cada ~4 segundos
  - Anillo de glow pulsante
  - Partículas flotantes
  - 4 estados con colores diferentes:
    - `idle`: violeta suave
    - `listening`: rojo/rosa pulsante
    - `thinking`: azul, partículas girando
    - `speaking`: verde, luna rebotando
- Integrado en `index.html` con Three.js CDN

### 4. Electron Window Controls
**Archivo:** `electron-app/src/index.html`
- **Problema:** Botones de minimizar y cerrar no hacían nada (handlers vacíos)
- **Solución:** Conectados a `window.lunaAPI.minimize()` y `window.lunaAPI.close()`

### 5. Scripts de Inicio Rápido
- `start.bat`: Script batch para CMD
- `start.ps1`: Script PowerShell con mejor UX
- Ambos instalan dependencias, inician Python service, y lanzan Electron

### 6. Tests
- `experiments/test-voiceclone-v2.py`: Test de voice clone con text processor mejorado
- `experiments/test-service-verify.py`: Verificación de todos los endpoints HTTP
