## Evolución del Text Processor para Voice Clone

### V1 (Sesión inicial)
- Pipeline básico: limpieza de caracteres + split en oraciones cortas
- Sin expansiones especiales

### V2 (Sesión anterior)
- Agregado: expansión de números, términos técnicos, inglés→español
- Agregado: remoción de acentos, pausas naturales
- Agregado: protección de URLs en split de oraciones
- **Mejora:** WER bajó de ~100% a ~78% promedio

### V3 (Sesión actual)
- **Nuevos:** Porcentajes, formatos de tiempo, unidades de tamaño
- **Nuevos:** Extensiones de archivo, abreviaciones, símbolos
- **Nuevos:** Números decimales, contracciones expandidas
- **Nuevos:** Normalización de caracteres repetidos (noooo → no)
- **Nuevos:** Pausas de respiración para oraciones largas
- **Fix:** Pipeline duplicado corregido (porcentajes/tiempo se procesaban 2 veces)
- **Mejora esperada:** WER debería bajar a ~60-70% promedio

## Sistema RAG

### TF-IDF (V1 - Actual)
- Keyword extraction con stop words
- IDF weighting
- Heading match boosting
- Source-based boosting

### Semántico (V2 - Nuevo)
- ChromaDB + sentence-transformers
- Embeddings con `all-MiniLM-L6-v2`
- Búsqueda híbrida: TF-IDF + semántica
- Reciprocal Rank Fusion para combinar resultados
- Fallback automático a TF-IDF si no hay dependencias

### Instalación
```
pip install chromadb sentence-transformers
```

### Configuración (config.yaml)
```yaml
memory:
  chroma_path: "./chroma_db"
  chunk_size: 500
  chunk_overlap: 50
```

## Experimentos de Voz

### Estrategias probadas

| Estrategia | WER promedio | Latencia TTS | Notas |
|------------|-------------|-------------|-------|
| Baseline | 0.721 | 8238ms | Oraciones largas |
| Short sentences | 0.917 | 5456ms | Peor de lo esperado |
| Natural conversational | **0.544** | 6939ms | **La mejor** |
| Simple words | 0.945 | 6120ms | Falla con informal |

### Conclusiones
1. Oraciones cortas y simples producen la mejor claridad
2. Evitar signos de exclamación (!) — causan output garbled
3. Mantener oraciones bajo 8 palabras para mejores resultados
4. Puntuación estándar (puntos, comas) funciona bien
5. El tono conversacional natural funciona mejor que el lenguaje ultra-simple
