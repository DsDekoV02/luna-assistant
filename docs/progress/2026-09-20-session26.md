### 2. ✅ Text Processor V6 — Limpieza de Reglas Fonéticas Incorrectas
**Archivo modificado:** `python-service/voice/text_processor.py`

**Cambios:**
- ❌ Eliminadas 30+ reglas de respelling fonético incorrectas:
  - Palabras con 'h' (hola→ola, hacer→aser, etc.) — La 'h' es muda en español y el TTS la maneja bien. Respelling causaba ASR hallucination.
  - Palabras con 'b/v' (vivo→bibo, verde→berde, etc.) — Mismo sonido en español latinoamericano. El TTS lo maneja naturalmente.
  - Palabras con 'c/z' (cerveza→serbesa, etc.) — Igual sonido en español.
  - Palabras con 'x' (extra→ekstra, etc.) — Innecesario.
- ❌ Eliminada expansión de contracciones ('al'→'a el', 'del'→'de el') — Son español estándar y suenan naturales en TTS. Expandirlas suena antinatural.
- ✅ Mantenidas solo las reglas que SÍ ayudan:
  - 'ps' clusters (psicologia→sicologia)
  - Nicknames (dekov, salocin)

**Tests actualizados:** 2 tests de contracciones actualizados para reflejar el nuevo comportamiento.

## Hallazgos Importantes

### Voice Clone Quality — Limitación del Modelo
- **WER promedio:** 88-106% (casi todo el texto es irreconocible)
- **No es un problema de text processing** — el pipeline V6 limpia correctamente el texto
- **No es un problema de referencia** — las 3 referencias producen resultados similares
- **Es una limitación del modelo `mimo-v2.5-tts-voiceclone`**
- El modelo produce audio que "suena" como la persona pero con palabras completamente malformadas

### Recomendaciones para el Futuro
1. **Usar TTS estándar** (`mimo-v2.5-tts`) en lugar de voice clone para producción
2. **Esperar a que Xiaomi mejore el modelo** de voice clone
3. **Explorar alternativas:** ElevenLabs, Coqui TTS, o modelos open-source
4. **Voice design** (`mimo-v2.5-tts-voicedesign`) podría ser mejor opción — genera voces personalizadas sin necesidad de referencia
