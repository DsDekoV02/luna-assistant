### 2. ✅ ASR Engine — Confidence Scoring + Usage Metrics
**Archivo modificado:** `python-service/asr/engine.py`

**Nuevos features:**
- **`transcribe_with_confidence()`** — Nuevo método que devuelve dict con:
  - `text`: texto transcrito
  - `confidence`: score 0.0-1.0 (API estima 0.85, Whisper calcula from word probabilities)
  - `backend`: "mimo-asr" o "whisper"
  - `language`: idioma detectado
  - `error`: None o string con tipo de error
- **Usage metrics tracking**:
  - `_transcribe_count`: total de transcripciones
  - `_error_count`: errores de API
  - `_api_success_count`: éxitos de API
  - `_whisper_success_count`: éxitos de Whisper
  - `success_rate`: ratio de éxito
- **`get_status()` mejorado** incluye todos los contadores y success_rate
- **Whisper confidence calculation**: usa `word_timestamps=True` para obtener probabilidades por palabra y promediar
