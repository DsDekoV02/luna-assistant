## Descubrimientos

### Voice Clone V4 Pipeline
El text processor V4 (última versión) tiene este pipeline:
1. Expandir formatos estructurados (%, tiempo, unidades)
2. Expandir abreviaciones y URLs
3. Expandir símbolos (&, @, =)
4. Limpiar caracteres especiales
5. Expandir números, términos técnicos, inglés
6. Aplicar respelling fonético
7. Normalizar caracteres repetidos
8. Aplicar pausas de ritmo
9. Remover acentos
10. Añadir pausas naturales
11. Dividir en oraciones cortas

### Semantic RAG
- Embedding model: `all-MiniLM-L6-v2` (multilingual)
- ChromaDB con cosine similarity
- Búsqueda híbrida: TF-IDF (40%) + semántica (60%)
- Reciprocal Rank Fusion para combinar resultados
- Fallback automático a TF-IDF si ChromaDB no disponible
