### 4. Experimento de Pronunciación Voice Clone ✅
**7 variantes de texto** generadas y evaluadas con ASR:

| Variante | WER | Mejor para |
|---|---|---|
| 🥇 **no_accents** | **37.5%** | Mejor claridad general |
| 🥈 simple | 62.5% | Alternativa |
| 🥉 clear_spoken | 66.7% | Nombre propio |
| pauses | 85.7% | No recomendado |
| periods | 100% | No recomendado |
| numbered | 111.1% | No recomendado |
| short | 125% | No recomendado |

**Descubrimientos clave:**
- Texto **sin acentos** produce la mejor claridad (WER 37.5% vs 62-125%)
- Oraciones cortas y simples son mejores que largas
- Puntuación con puntos y comas funciona, pero exceso empeora
- El modelo ASR aún tiene problemas con voces TTS clonadas
- "Hola Nicolas" a veces se transcribe como "El nicholas" o "Ola nicolas"
