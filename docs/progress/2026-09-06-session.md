### 2. ASR (Speech-to-Text) ✅ FUNCIONA
- **Problema encontrado:** El formato correcto es `input_audio` como tipo de content
- **Formato correcto:**
  ```json
  {
    "role": "user",
    "content": [
      {
        "type": "input_audio",
        "input_audio": {
          "data": "<base64>",
          "format": "wav"
        }
      }
    ]
  }
  ```
- **Transcripción de luna_voz_v5b:** "O la neclaz, soi luna, mi aligrammo ce stai con dogigo..."
- **Nota:** ASR tiene dificultades con voces TTS clonadas (esperado)
- **Tiempo promedio:** ~4 segundos
