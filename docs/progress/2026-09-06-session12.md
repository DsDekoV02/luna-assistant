### 2. Text Processor V4 — Bugs corregidos ✅

#### Bug 1: Double periods (`..`)
**Causa:** `add_breathing_pauses()` unía oraciones con `. ` pero las oraciones ya tenían puntuación final.
**Fix:** Cambiar `'. '.join(result)` → `' '.join(result)`.

```
ANTES: "Hola Nicolas.. Como estas?. Soy Luna."
DESPUÉS: "Hola Nicolas. Como estas? Soy Luna."
```

#### Bug 2: Phonetic respelling `qu→k` empeoraba calidad
**Causa:** `PHONETIC_RESPELLING` convertía `que→ke`, `quiero→kiero`, `porque→porke`.
**Problema:** El TTS maneja "qu" español naturalmente; las formas "ke/kiero" causaban que el ASR alucinara (WER >80%).
**Fix:** Eliminadas 10 entradas del diccionario `PHONETIC_RESPELLING` para palabras con "qu".

```
ANTES: "Quieres que revise" → "Quieres ke revise"  (ASR: garbled)
DESPUÉS: "Quieres que revise" → "Quieres que revise"  (ASR: correcto)
```

#### Bug 3: Encoding en Windows
**Causa:** El carácter `→` (U+2192) en el texto del error de la API causaba `charmap codec error`.
**Fix:** Ejecutar con `$env:PYTHONIOENCODING="utf-8"`.

