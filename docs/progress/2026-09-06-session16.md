## Nuevos Sistemas Implementados

### 1. Memoria Persistente de Conversaciones
**Archivo:** `python-service/memory/conversation.py`

Sistema que guarda el historial de conversaciones en disco para que Luna recuerde entre reinicios.

**Componentes:**
- `ConversationTurn`: Un turno individual (role, content, timestamp, metadata)
- `ConversationSession`: Una sesión de conversación con múltiples turnos
- `ConversationMemory`: Manager principal con persistencia JSON

**Funcionalidades:**
- Guarda conversaciones automáticamente cada 5 mensajes
- Carga contexto de conversaciones anteriores al iniciar
- Búsqueda por keywords en todo el historial
- Análisis de preferencias del usuario (horas activas, temas frecuentes, ratio de preguntas)
- Limpieza automática de sesiones antiguas (configurable, default 30 días)
- Estadísticas de uso

**Endpoints nuevos:**
- `GET /conversations` — Listar sesiones recientes
- `GET /conversations/search?q=` — Buscar en historial
- `GET /conversations/stats` — Estadísticas de memoria
- `GET /conversations/preferences` — Preferencias del usuario

### 2. Detección de Emociones + Respuesta Adaptativa
**Archivo:** `python-service/brain/emotion.py`

Sistema que detecta la emoción del usuario desde el texto y adapta el estilo de respuesta de Luna.

**Emociones detectadas:**
- 😊 Happy, 🤩 Excited, 😢 Sad, 😤 Frustrated, 😠 Angry
- 😰 Anxious, 😴 Tired, 🤔 Curious, 😕 Confused, 🥰 Grateful
- 😏 Sarcastic, 😐 Neutral

**Cómo funciona:**
1. Keyword matching con scoring de confianza
2. Detección de intensidad (CAPS, !!!, mensajes cortos/largos)
3. Mapeo a `ResponseStyle` que modifica el system prompt de MiMo
4. Historial de emociones para detectar tendencias de ánimo

**Adaptaciones de estilo:**
- Happy/Excited → tono cálido, entusiasta, más emojis
- Sad/Angry → tono suave, respuestas breves, consuelo
- Tired → respuestas cortas, tono gentile
- Curious → respuestas detalladas
- Frustrated → tono calmado, validar sentimientos

**Endpoint nuevo:**
- `GET /emotion/stats` — Estadísticas de detección
