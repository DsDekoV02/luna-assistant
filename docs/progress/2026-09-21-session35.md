### 1. ✅ Security Hardening — validate_command allowlist check
**Problema:** `validate_command()` en `tools/security.py` no verificaba si el comando estaba en la allowlist. Solo validaba parámetros. Comandos desconocidos como "evil_command" pasaban la validación (aunque serían rechazados por `allowlist.execute()`).

**Fix:** Agregado check de allowlist al inicio de `validate_command()` como defensa en profundidad:
```python
from tools.allowlist import get_allowlist
allowlist = get_allowlist()
if not allowlist.is_allowed(command):
    return False, f"Command '{command}' is not in the allowlist"
```

**Resultado:** Ahora `evil_command` es rechazado en la capa de validación:
- Antes: `valid=True` (pasaba validación, rechazado en ejecución)
- Después: `valid=False, err=Command 'evil_command' is not in the allowlist`
