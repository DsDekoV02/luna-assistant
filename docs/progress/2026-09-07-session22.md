### 1. ✅ Async TTS Pipeline — Non-blocking voice generation
**Archivos modificados:**
- `python-service/voice/tts.py` — Added `speak_async()` method
- `python-service/main.py` — WebSocket handler uses `asyncio.create_task()` for TTS
- `python-service/voice/streaming.py` — `speak_response()` uses async TTS

**Problema anterior:**
El TTS bloqueaba el event loop de asyncio. Cuando Luna generaba una respuesta de texto, el audio se generaba *después* del texto pero bloqueaba el envío de chunks de texto siguientes. Esto causaba:
- Pausas largas entre chunks de texto
- Latencia percibida alta
- El avatar no podía pasar a "speaking" hasta que el audio estuviera listo

**Solución:**
- `speak_async()` ejecuta el TTS blocking en un thread pool via `loop.run_in_executor()`
- El WebSocket handler usa `asyncio.create_task()` para fire-and-forget
- El texto se envía inmediatamente como streaming chunks
- El audio sigue en background y se envía cuando está listo
- El avatar cambia a "speaking" cuando el audio llega al cliente

**Flujo mejorado:**
```
1. Usuario envía mensaje
2. Luna procesa (thinking...)
3. Texto se envía como streaming chunks (inmediato)
4. [Background] TTS genera audio en thread pool
5. Audio se envía cuando está listo
6. Avatar cambia a "speaking"
```

### 2. ✅ ASR Respelling Dictionary — Fix proper nouns
**Archivos modificados:**
- `python-service/voice/text_processor.py` — Added `ASR_RESPELLING` dict + `fix_asr_names()`
- `python-service/voice/stt.py` — Auto-applies `fix_asr_names()` after transcription

**Problema:**
ASR (mimo-v2.5-asr) consistentemente malinterpretaba nombres propios:
- "Dekov" → "de kov", "the kov", "de cob"
- "Salocin" → "sallo sin", "sallo cin", "sala sin"
- "OpenClaw" → "open claw"
- "MiMo" → "mi mo"

**Solución:**
Diccionario de respelling que se aplica como post-procesamiento al output del ASR. Incluye:
- Nombres del usuario (Dekov, Salocin) con variantes conocidas
- Términos técnicos del proyecto (OpenClaw, MiMo, Luna JARVIS)
- Matching case-insensitive, preserva texto circundante
- Solo reemplaza la primera aparición para evitar over-correction
