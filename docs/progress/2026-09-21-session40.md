### 1. ✅ Backend Compound Emotion Detection
**Archivo modificado:** `python-service/brain/emotion.py`

**Problema:** Las emociones compuestas (compound) solo se detectaban en el frontend. El backend no tenía esta lógica.

**Implementación:**
- Nuevo dict `COMPOUND_EMOTIONS` con8 perfiles: delight, shy_joy, bitter, amazed, playful, vulnerable, shocked, joyful
- Nueva función `detect_compound(current, previous, intensity)` — detecta transiciones emocionales cuando intensity > 0.5
- `EmotionState` ahora incluye campo `compound: Optional[Dict]`
- `EmotionDetector` trackea `_previous` emotion para detectar transiciones
- `to_dict()` incluye compound info cuando existe
- Nuevo método `get_history()` — devuelve historial serializable para charts
- Nuevo método `reset()` — limpia historial y estado previo
- `get_stats()` ahora incluye `compound_count`

**Test results:**
```
happy (0.65) → excited (0.65): no compound (not defined)
sad (0.5) → angry (0.75): compound=bitter ✅
```

### 2. ✅ Emotion History API Endpoint
**Archivo modificado:** `python-service/main.py`

**Nuevo endpoint:** `GET /emotion/history`
- Devuelve `{"history": [...], "total": N}`
- Cada entrada: `{emotion, confidence, intensity, compound, secondary}`
- Ideal para charts de series temporales en el dashboard

**Verified:**
```json
{
  "history": [
    {"emotion": "happy", "confidence": 1.0, "intensity": 0.65, "compound": null, "secondary": "excited"},
    {"emotion": "angry", "confidence": 1.0, "intensity": 0.65, "compound": {"name": "bitter", ...}, "secondary": "excited"}
  ],
  "total": 4
}
```

### 3. ✅ Emotion Evolution Sparkline Chart
**Archivo modificado:** `electron-app/src/index.html`

**Nuevo feature:** Mini chart canvas que muestra la evolución de emociones en el tiempo.

**Implementación:**
- Función `renderEmotionSparkline()` — Canvas 2D con línea de intensidad + gradient fill
- Cada punto es un dot con color de la emoción (o compound color)
- Dots con intensidad > 0.7 tienen glow effect
- Se renderiza automáticamente al actualizar emociones (live) y al abrir dashboard
- Línea púrpura con gradient fill — coherente con el tema visual de Luna
