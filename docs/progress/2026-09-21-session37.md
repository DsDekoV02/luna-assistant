### 1. ✅ TTS Mouth Sync — WebSocket Integration
**Archivo modificado:** `electron-app/src/index.html`

**Problema:** Session 36 creó los métodos `setMouthAmplitude()` y `stopMouthSync()` en el avatar, pero el frontend solo usaba un `Audio` element básico sin análisis de amplitud.

**Implementación:**
- Reemplazado `playAudio()` con Web Audio API completa
- `AudioContext.decodeAudioData()` para decodificar WAV base64
- `AnalyserNode` con `fftSize=256` y `smoothingTimeConstant=0.4` para análisis en tiempo real
- Loop `requestAnimationFrame` que calcula amplitud normalizada (0-1) y la pasa a `lunaAvatar.setMouthAmplitude()`
- Suavizado extra (70/30 blend) para evitar jitter
- `source.onended` callback que limpia el animation frame y llama `stopMouthSync()`
- Fallback a `Audio` element básico si `decodeAudioData` falla

**Resultado:** La boca de Luna ahora se sincroniza en tiempo real con la amplitud del audio TTS.

### 2. ✅ Avatar — Nuevas Emociones: Surprised + Embarrassed
