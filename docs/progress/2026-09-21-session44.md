1. Saludo — "¡Hola Nicolas! Soy Luna..."

```bash

```

### 5. ✅ Nuevos API Endpoints

**`GET /voice/backends`** — Lista todos los backends TTS disponibles con su estado:
- Edge (voice, quality, cost)
- Clone (reference audio, quality, cost)
- Design (profile, quality, cost)
- Standard (quality, cost)

**`POST /voice/compare`** — Ejecuta comparación completa de todos los backends:
- Genera WAV con cada backend para5 frases de prueba
- Devuelve metadata: tamaño, tiempo de generación, status

**`POST /voice/test_phrase`** — Genera TTS para una frase con un backend específico:
- Útil para pruebas rápidas desde la UI
- Devuelve audio base64 + metadata

**`GET /conversations/export`** — Exporta historial de conversaciones:
- `format=json` — Estructura JSON con sesiones y mensajes
- `format=markdown` — Documento Markdown legible
- Parámetro `limit` para controlar cuántas sesiones exportar
